# Simulation Engineering Toolkit 08 — Jira and Engineering Metrics

The tracker as a simulation team's data model: issue types, workflows and status categories, versions, sprints and Kanban, JQL with worked queries and its traps, Git and Jenkins integration, traceability from requirement to build, the metrics worth reporting, flow metrics and Little's law from a workflow history, and evidence for sign-off.

Topics: Issue model, Workflows, JQL, Smart commits, Flow metrics, Sign-off.
